## 1. Typograpy 스타일링

### 1.1. 글꼴크기(text-)
```html
<p class="text-xs">이 문장은 작은크기 입니다.</p>
<p class="text-sm">이 문장은 더 작은 크기 입니다.</p>
<p class="text-base">이 문장은 기본 크기 입니다.</p>
<p class="text-lg">이 문장은 큰크기 입니다.</p>
<p class="text-xl">이 문장은 더 큰 크기 입니다.</p>
```
### 1.2. 글꼴두께(font-) 
```html
<p class="font-light">이 문장은 얇은 글씨 입니다</p>
<p class="font-normal">이 문장은 보통 글씨 입니다</p>
<p class="font-bold">이 문장은 굵은 글씨 입니다</p>
<p class="font-black">이 문장은 굵은 글씨 입니다</p>
```
### 1.3. 텍스트정렬(text-)
```html
text-center, text-left, text-right
```
### 1.4. 텍스트색상(text-)
```html
text-red-500, text-blue-500, text-green-500
```
### 1.5. 줄 간격(leading-)
```html
leading-none, leading-tight, leading-relaxed
```
### 1.6. 텍스트 오버플로우(text-)
```html
text-ellipsis, text-clip, text-nowrap
```
### 1.7. 텍스트 오버플로우(text-) : truncate
```html
<p class="truncate">이 문장은 텍스트 오버플로우를 방지합니다.</p>
```
| 클래스  | CSS 속성  | 설명  |
| :-- | :-- | :-- |
| truncate | text-overflow: ellipsis; overflow: hidden; white-space: nowrap; | 한 줄로 표시하고 넘치면 '...'로 표시 |
| text-clip | text-overflow: clip; | 넘치는 텍스트를 잘라버림 |
| text-nowrap | white-space: nowrap; | 텍스트를 한 줄로 표시 |
| text-ellipsis | text-overflow: ellipsis; | 텍스트를 ...으로 표시 |


#### truncate의 동작원리 
```html
1. white-space: nowrap; // 텍스트를 한줄로 표시
2. overflow: hidden; //  넘치는 텍스트를 숨김
3. text-overflow: ellipsis; // 넘치는 텍스트를 ...으로 표시
```
