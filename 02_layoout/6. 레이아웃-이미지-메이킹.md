
## 1. 화면 전체 이미지

```text
┌──────────────────────────────────────────────────────┐
│ Header                                               │
├───────────────┬──────────────────────────────────────┤
│               │                                      │
│      LNB      │  ┌────────────────────────────────┐  │
│               │  │ Main                  [border] │  │
│  메뉴 A        │  │  제목                          │  │
│  메뉴 B        │  │  검색조건                       │  │
│  메뉴 C        │  │ ┌────────────────────────────┐ │  │
│  메뉴 D        │  │ │ 검색조건                    │ │  │
│  메뉴 E        │  │ └────────────────────────────┘ │  │
│  메뉴 F        │  │                                │  │
│      ↕        │  │  검색 결과              [sticky] │  │
│   scrollbar   │  │  ┌────────────────────────────┐ │  │
│               │  │  │ Table thead      [sticky]  │ │  │
│               │  │  ├────────────────────────────┤ │  │
│               │  │  │ Table tbody      ↕         │ │  │
│               │  │  │                overflow-y  │ │  │
│               │  │  │                auto        │ │  │
│               │  │  └────────────────────────────┘ │  │
│               │  │                                 │  │
│               │  └────────────────────────────────┘  │
└───────────────┴──────────────────────────────────────┘
```

## 2. 화면 3 개 영역

| 영역 | 서브 | 세부 | 일반적인 처리 |
| :-- | :-- | :-- | :-- |
| Header 영역  | -         |                  |  -                                                   |
| LNB    영역  | 메뉴 리스트 |                  | 메뉴 리스트가 요소가 많으면 세로 스크롤, `overflow-y-auto` |
| Main   영역  | (Main)    |                   | 일반 영역                                             |
|             | ├─ 검색조건 |                   | 검색조건 고정, `sticky top-0`                         |
|             | └─ 검색결과 | (검색결과)         | -                                                   |
|             |            | ├─ Table `thead` | 별도의 `overflow-y-auto` 컨테이너                      |
|             |            | └─ Table `tbody` | 세로 스크롤                                           |

웹 관리자 페이지(어드민, 대시보드)에서 가장 널리 쓰이는 **"화면 꽉 찬 고정형 레이아웃(App Shell Layout)"의 정석 코드**입니다.

브라우저 창 전체를 100% 활용하면서 **헤더와 사이드바 크기는 고정**하고, **본문과 사이드바가 독립적으로 동작**하도록 설계되어 있습니다.

## 3. html 코드
```html
<body class="h-screen flex flex-col">

    <!-- Header -->
    <header class="bg-gray-500 h-16 shrink-0 sticky top-0 z-50">
        Header
    </header>

    <!-- Header 아래 전체 영역 -->
    <page class="flex-1 min-h-0 flex">

        <!-- LNB -->
        <aside class="bg-gray-300 w-64 shrink-0 overflow-y-scroll">
            LNB
        </aside>

        <!-- Main -->
        <main class="bg-gray-100 flex-1 min-w-0">
            Main
        </main>

    </page>
</body>
```

### 3.1. `body` (전체 틀 잡기)
```html
<body class="h-screen flex flex-col">
```
* **`h-screen`**: 브라우저 창 높이를 100%(`100vh`)로 딱 맞춥니다. (창 밖으로 전체 스크롤이 생기지 않음)
* **`flex flex-col`**: 자식 요소인 `<header>`와 `<page>`를 **위아래(수직)**로 배치합니다.

---

### 3.2. `header` (상단 영역 고정)
```html
<header class="bg-gray-500 h-16 shrink-0 sticky top-0 z-50">
```
* **`bg-gray-500`**: 배경색을 진 회색으로 설정합니다. (background-color: rgb(107 114 128);)
* **`h-16`**: 높이를 64px(`4rem`)로 고정합니다.
* **`shrink-0` (⭐ 중요)**: 화면이 좁아지더라도 헤더 높이가 **찌그러지거나 줄어들지 않도록 방지**합니다.
* **`sticky top-0 z-50`**: 최상단에 고정하며 다른 요소 위에 표시되도록 레이어 순서(z-index)를 높입니다.

---

### 3.3. `page` (헤더를 제외한 나머지 화면 전체)
```html
<page class="flex-1 min-h-0 flex">
```
* **`flex-1`**: 전체 화면에서 헤더(64px)를 뺀 **남은 세로 공간 전부를 차지**합니다.
* **`min-h-0` (⭐ 중요)**: Flexbox의 기본 동작(내용물만큼 커지려는 성질)을 차단하여, **자식 요소들의 스크롤(`overflow`)이 정상 작동**하게 만듭니다.
* **`flex`**: 내부의 `<aside>`(LNB)와 `<main>`을 **좌우(가로)**로 배치합니다.

---

### 3.4. `aside` (LNB 사이드바)
```html
<aside class="bg-gray-300 w-64 shrink-0 overflow-y-scroll">
```
* **`bg-gray-300`**: 배경색을 연 회색으로 설정합니다. (background-color: rgb(209 213 219);)
* **`w-64`**: 너비를 256px(`16rem`)로 고정합니다.
* **`shrink-0` (⭐ 중요)**: 우측 `main` 영역에 내용이 많아져도 **사이드바 너비가 좁아지지 않고 유지**됩니다.
* **`overflow-y-auto`**: 메뉴가 화면 하단보다 길어지면 **사이드바 영역 안에서만 세로 스크롤**이 생깁니다.

---

### 3.5. `main` (메인 본문)
```html
<main class="bg-gray-100 flex-1 min-w-0">
```
* **`bg-gray-100`**: 배경색을 아주 연한 회색으로 설정합니다. (background-color: rgb(243 244 246);)
* **`flex-1`**: 사이드바(256px)를 제외한 **오른쪽 남은 가로 공간을 100% 채웁니다.**
* **`min-w-0` (⭐ 중요)**: 본문에 가로로 긴 표(Table)나 긴 텍스트가 들어와도, 화면을 뚫고 나가 전체 레이아웃을 깨뜨리지 않도록 가로 한계를 지정합니다. (필요 시 `overflow-y-auto`를 추가하여 본문 전용 스크롤을 만듭니다.)

---

### 3.6. 한 줄 요약
> **"브라우저 전체를 꽉 채우고, 헤더와 사이드바 크기는 절대 찌그러지지 않게 고정한 뒤, 남은 공간을 본문이 다 쓰도록 만든 레이아웃"**입니다.
