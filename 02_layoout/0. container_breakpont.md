## container: 
- 요소의 너비를 현재 브레이크포인트에 고정하는컴포넌트입니다.
- 웹 레이아웃의 주요 콘텐츠를 담는 요소.


### Breakpoints
| Class | Breakpoint | Properties |
| :---: | :---: | :---: |
| container | None | width: 100%; |
| container | sm (640px) | max-width: 640px; |
| container | md (768px) | max-width: 768px; |
| container | lg (1024px) | max-width: 1024px; |
| container | xl (1280px) | max-width: 1280px; |
| container | 2xl (1536px) | max-width: 1536px; |

### None : 모든 화면 크기에서 컨테이너 규칙이 적용됩니다.
```html
<div class="container mx-auto"></div>
```

### sm : 컨테이너는 기본 적용하되, 가운데 정렬만 640px 이상에서 하고 싶다.  
```html
<div class="container sm:mx-auto"></div>
```

### md : 768px 이상에서부터 컨테이너 규칙을 시작하고 싶다.
```html
<div class="md:container md:mx-auto"></div>
```
